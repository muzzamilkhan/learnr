# NSW Mathematics K–10 (2022) — outcome codes by stage

Reference for the Phase 3 content tasks. Cite a code from the stage matching the
template's year. `catalog.test.ts` (Task 22) enforces the stage match.

**Copy no NESA prose into the repo.** The right-hand column below is *my* one-line
gloss of what the focus area covers, written to help you choose a code — it is not
NESA's outcome statement, and neither it nor any outcome statement goes into a
`tags` array, a comment, or the curriculum page. A tag is a bare code. Nothing else.

Sources: the official outcomes page at
`curriculum.nsw.edu.au/learning-areas/mathematics/mathematics-k-10-2022/outcomes`,
cross-checked against two independent published alignment guides. The Stage 3 set
below (21 codes over 10 focus areas) was recovered from those guides after the
official site would not render Stage 3, and both guides agree on it.

`MAO-WM-01` (Working mathematically) attaches to every outcome at every stage.
**Do not cite it on a template** — it has no stage, `nswStageOfCode` returns null
for it, and a generated single-answer question cannot evidence it. See the spec.

## Content NSW places beyond Year 6

Do **not** invent a Stage 3 code for these. They stay ACARA-only (Task 21):

- **Integers** — negative numbers ordered or operated on. NSW: Stage 4,
  `MA4-INT-C-01`, Year 7. Stage 3 lets a negative *result* from a subtraction and
  goes no further.
- **Four-quadrant Cartesian plane** — `MA3-GM-01` is the first quadrant only.
  The number pad has no minus key, so our content is already first-quadrant.
